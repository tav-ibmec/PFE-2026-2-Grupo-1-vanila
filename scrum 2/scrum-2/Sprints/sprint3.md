# Sprint 3 — Desenvolvimento e integração dos sites

## Objetivo da Sprint

Avançar no desenvolvimento dos sites PKZ, One to One e HUB, distribuindo as tarefas de HTML, CSS, JavaScript e agendamento, além de manter a revisão e a integração dos códigos.

## Atividades planejadas

- Desenvolver o HTML das páginas PKZ, One to One e HUB.
- Implementar a parte de agendamento dos sites PKZ e One to One.
- Desenvolver o JavaScript e o CSS do projeto.
- Revisar os códigos e realizar commits frequentes no repositório.
- Integrar os componentes e testar o funcionamento dos sites.
- Corrigir possíveis erros identificados durante os testes.

## Distribuição das atividades

- **Lucas:** agendamento dos sites PKZ e One to One.
- **João:** HTML da PKZ.
- **Rebeca:** HTML do HUB.
- **Yasmin:** HTML do One to One.
- **Manuela:** JavaScript.
- **Pedro:** CSS.

## Resultado esperado

Avançar na construção dos três sites, com as partes de HTML, agendamento, JavaScript e CSS desenvolvidas e preparadas para integração e testes.

## Critérios de conclusão

- [ ] HTML da PKZ desenvolvido.
- [ ] HTML do HUB desenvolvido.
- [ ] HTML do One to One desenvolvido.
- [ ] Agendamento dos sites PKZ e One to One implementado.
- [ ] JavaScript e CSS desenvolvidos.
- [ ] Códigos revisados e postados no repositório.
- [ ] Integração e testes realizados, com correção dos erros identificados.

## Status da Sprint

A Sprint está em andamento, com foco no desenvolvimento das partes atribuídas e na integração dos componentes dos sites.

## Impedimentos e pendências

- Dependência entre as partes de HTML, CSS, JavaScript e agendamento para concluir a integração.
- Necessidade de revisar os códigos e resolver possíveis conflitos no repositório.
- Testes necessários para confirmar o funcionamento conjunto dos sites.

## Revisão da Sprint

Ao final da Sprint, o grupo deverá verificar o andamento das partes de cada site, confirmar a integração dos componentes e avaliar os resultados dos testes.

## Retrospectiva

O grupo deverá avaliar a divisão das tarefas, a comunicação durante o desenvolvimento, a colaboração na revisão dos códigos e as dificuldades encontradas na integração, identificando melhorias para a próxima Sprint.
