# Pontos importantes do áudio 3

## Identidade Visual e Marca
- Solicitação de arquivos de logo e paleta de cores oficial da empresa.
- O cliente confirmou a existência de uma pasta no Google Drive com esses materiais.
- A paleta base para as duas empresas é composta pelas cores azul e branco.
- Destaque para a importância de utilizar os códigos exatos de cor (código hex/RGB), pois exibições em telas de celulares podem alterar a percepção das tonalidades (ex.: azul padrão x azul ciano).

## Fotografias e Conteúdo Visual:
- As fotos atuais da empresa são antigas, mas há planos para contratar uma fotógrafa para produzir novas imagens.
- Caso a equipe do site precise de fotos urgentes, o cliente pode tentar acelerar esse processo.
- Importância de boas fotos e enquadramentos para a aplicação web/site, incluindo o uso de imagens dos equipamentos e visual dos ambientes internos.

## Divisão de Trabalho da Equipe/Curso:
- O projeto é dividido entre várias turmas e períodos:
- Turma atual: Focada no front-end, design e criação do site/estética visual.
- Outras turmas: Focadas em banco de dados, formulários e integração de produtos/dados.

## Compartilhamento de Arquivos:
- Acordo para o envio das logos, códigos de cores e materiais via download/compartilhamento direto para a equipe de desenvolvimento.
