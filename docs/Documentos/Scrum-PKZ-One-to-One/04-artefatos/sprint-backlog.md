# Sprint Backlog

Exemplo de tarefas selecionadas para uma Sprint de revisão:

- Conferir os artefatos de documentação.
- Revisar o protótipo e a navegação no Figma.
- Verificar a página de cadastro e sua consistência visual.
- Conferir os AHTs e o 5W2H.
- Registrar pendências e preparar os materiais para apresentação.
